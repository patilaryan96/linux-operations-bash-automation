# Linux Operations & Bash Automation Toolkit

A collection of Bash scripts covering Linux command-line operations, file management, permissions, text processing, process management, system monitoring, scheduled tasks, and advanced shell scripting.

## Topics Covered

| Folder | Topics |
|---|---|
| [01 - Linux Shell Fundamentals](01-linux-shell-fundamentals/) | Basic commands, variables, user input, system information |
| [02 - Conditionals & Permissions](02-conditionals-and-permissions/) | Conditional statements, file checks, permissions |
| [03 - Loops & Iteration](03-loops-and-iteration/) | For loops, while loops, iteration over files and users |
| [04 - Functions & Reusable Scripts](04-functions-and-reusable-scripts/) | Functions, arguments, file checks, menu-driven scripts |
| [05 - Arrays & String Processing](05-arrays-and-string-processing/) | Arrays, string length, comparison, searching |
| [06 - File Operations & Backups](06-file-operations-and-backups/) | File creation, reading, counting, searching, backups |
| [07 - Redirection & Pipelines](07-redirection-and-pipelines/) | Input/output redirection, pipes, command chaining |
| [08 - Error Handling & Script Safety](08-error-handling-and-script-safety/) | Exit codes, command validation, safer scripts |
| [09 - Command-Line Arguments & Options](09-command-line-arguments-and-options/) | Argument parsing and validation |
| [10 - Regex, Globbing & Text Processing](10-regex-globbing-and-text-processing/) | Regular expressions, globbing, grep, sed, awk basics |

## Running a Script

Navigate to the relevant topic directory and execute a script:

```bash
cd 13-process-management-and-scheduling
bash 64-system-monitor.sh
```

Some scripts may require specific permissions, input files, utilities, or system privileges. Review each script and its folder README before running it.

## Project Structure

The repository is organized by technical topic. Each topic directory contains its Bash scripts and a README explaining the exercises.

This project documents practical Bash scripting exercises and ongoing learning in Linux operations, automation, text processing, monitoring, and troubleshooting.
